# v0.5 功能变更说明

## 用户提出的三项变更

1. 左侧「已导入结构」每条材料增加红色删除按钮。未被任务引用时删除
   工作区副本；已有历史任务时从工程树归档，不破坏历史和重跑功能。
   SQLite 启动时安全迁移 `materials.archived_at`。
2. 右侧新增「计算类型」下拉框，按 3 个业务类型动态提供真实的
   `bgp predict --backend` 选项：
   - 机器学习带隙误差修正 -> `gnn-hse06`
   - GPU 带隙计算 -> `abacus-hse06` / `abacus-pbe0`
   - 数据驱动泛函带隙计算 -> `cider-pbe0`
3. 新增中心「计算报告」标签。工具栏「计算报告」打开当前标签，
   直接显示所选任务 `result.json` 与任务记录；另有导出 TXT、
   手动打印/保存 PDF，不会默认新开浏览器页面。

## 继承功能

保持 v0.4 原有布局、图标、日志、任务、结构查看、导入、结果、
比较、导出、调度、工作区和安全边界。
未修改 `D:\program\gnnbgp` 计算源码与模型。

## 运行限制

ABACUS/CIDER 依然必须在对应系统编译并验证 GPU/MPI 专用 ABACUS 可执行文件。
`tests/fake_bgp.py` 仅用于接口测试，不是科研计算器。
