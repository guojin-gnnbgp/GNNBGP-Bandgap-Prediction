# PseudoDojo NC scalar-relativistic collection

This directory contains 71 element-named UPF files copied unchanged from the
project-supplied `Dojo-NC-SR/Pseudopotential` collection. Runtime lookup is by
chemical symbol and every file is verified against `assets/manifest.json`.

The UPF headers retain generator and citation information. See
`assets/NOTICE.md` for the integration convention and redistribution-review
status.
