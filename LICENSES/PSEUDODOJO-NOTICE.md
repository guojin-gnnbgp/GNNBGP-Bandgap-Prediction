# Supplied PseudoDojo collection

The 71 scalar-relativistic, norm-conserving UPF files were supplied unchanged
from the project PseudoDojo collection. Each file retains its embedded ONCVPSP
generator, author, and citation information. The suggested generator citation
is D. R. Hamann, *Physical Review B* **88**, 085117 (2013).

No standalone redistribution license accompanied the supplied directory.
Public redistribution therefore requires a separate review; this project does
not infer or assert rights beyond the notices embedded in the files.
